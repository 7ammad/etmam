# Code reviewer

Use the **code-reviewer** subagent to review the selected code, recent changes, or the current PR.

- Conduct a structured review: context → security → performance → type safety → code quality.
- Report by severity (critical / high / medium / low) with file paths and recommendations.
- End with executive summary and verification checklist.

Focus on Next.js, Supabase, TypeScript; include RTL/Arabic and project standards where relevant.
