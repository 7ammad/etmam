# Subagent advisor

Use the **subagent-advisor** subagent to recommend or optimize subagents.

- Analyze project structure and workflows for subagent opportunities.
- Recommend 2–5 focused subagents (context-heavy, parallel, specialized, noisy output).
- Apply best practices: single responsibility, specific descriptions, model choice (fast vs inherit).
- Output: recommended subagents with rationale, anti-patterns to avoid, and implementation priority.

Use when planning subagent architecture, identifying delegation opportunities, or reviewing existing subagents.
