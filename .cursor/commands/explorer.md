# Explorer

Use the **explorer** subagent to research the codebase or docs.

- Answer the user's question: how something works, where something is used, what the flow is, what docs exist.
- Run targeted semantic searches and grep; synthesize findings—no raw dumps.
- Return: direct answer, key files with roles, details (flows/usages), and caveats.

Deep research in isolated context; parent gets only the summary report.
